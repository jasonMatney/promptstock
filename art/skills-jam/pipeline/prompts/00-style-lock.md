# Style lock — Promptstock Skills Jam

Use this file (and the attached still) on **every** Astra / GPT Image call for this project.

## Attach

- `art/skills-jam/pipeline/references/visual_target_01.jpg` (canonical style lock; same frame as the festival stage golden)

## Style paragraph (copy verbatim into prompts)

A stylized summer AI festival — warm dusk light, painterly meadow and foliage cards, friendly low-poly booths and crowd, soft Puerto Rican concert color on stage screens — playful and readable at first-person height, not photoreal, not grimdark.

## Look keywords

- Cozy festival, friendly, readable silhouettes
- Soft dusk / late-afternoon warmth, gentle bloom feel (not HDR glare)
- Painterly meadow greens, soft foliage cards, low-poly booth canvas
- Soft Caribbean / Puerto Rican concert screen colors (coral, teal, sunset peach) as accents — not neon cyberpunk
- First-person eye height (~1.82 m); props and characters must read clearly at that scale

## Negative guidance (always include)

- No photoreal photography, no Unreal/Cinema4K realism
- No UI chrome, HUDs, watermarks, captions, or mock app frames
- No grimdark, horror, blood, dystopia
- No generating Blender files, `.blend`, GLB, FBX, or “3D print ready STL”
- No cluttered product-catalog white void unless the kit prompt asks for a clean prop sheet
- Do not invent a new art direction that fights `visual_target_01.jpg`

## What to ask for (image types)

| Deliverable | Use |
| --- | --- |
| Orthographic turnaround sheet | Front / side / back / 3⁄4 — Blender modeling reference |
| Prop sheet | Grid of named props, consistent lighting |
| Seamless texture tile | Albedo (and optional roughness/detail) for materials |
| Concept sheet | Color / silhouette exploration before modeling |

## What never to ask for

- “Generate a Blender scene / .blend / game-ready GLB”
- Photoreal PBR product renders as the primary look target
